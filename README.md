# 赛鸽遗传育种系统

TypeScript 实现的赛鸽遗传育种引擎与可视化应用,回应「配了二十代后代还是随机」的核心质疑:
**每一个羽色位点按真实显隐性遗传,数量性状按多基因 + 环境建模,近交按标准亲缘算法精确计算且可解释。**

## 遗传模型

### 羽色(质量性状,6 个基因位点)

| 位点 | 遗传方式 | 等位与显隐 |
|---|---|---|
| 基础色 `base` | **Z 性连锁** | 红绛 Bᴬ > 蓝 B⁺ > 褐 b;雌鸽半合子 |
| 纹样 `pattern` | 常染色体,4 等位级序 | 深雨点 Cᵀ > 雨点 C > 灰杠 c⁺ > 无杠 c |
| 黑羽 `spread` | 常染色体显性 | S > +,黑化覆盖纹样 |
| 隐性红 `recessiveRed` | 常染色体隐性 | ee 纯合覆盖基础色 |
| 稀释 `dilute` | 常染色体隐性 | dd 纯合整体淡化 |
| 石斑 `grizzle` | **不完全显性** | GG 重石斑 / Gg 石斑 / ++ 无 |

位点间互作(隐性红 → 黑化 → 基础色+纹样 → 稀释 → 石斑)在 `src/genetics/color.ts` 推断表现型。

### 速度 / 耐力 / 归巢(数量性状)

标准数量遗传学模型,每个性状 10 个加性微效位点:

```
P(表型) = μ(群体均值) + A(育种值) − b·F(近交衰退) + E(环境偏差),E ~ N(0, σ_E²)
遗传力 h² = σ_A² / (σ_A² + σ_E²)   # 速度 0.40 / 耐力 0.35 / 归巢 0.45
```

另有 6 个**有害隐性位点**,纯合即发病,每发病位点对三性状各扣 4 分(遗传负荷)。

### 近交衰退

近交系数 F 线性压低表型(速度每单位 F 降 12 分、耐力 10、归巢 14),并降低孟德尔分离方差。

## 近交系数:三套实现互验

| 算法 | 用途 | 特点 |
|---|---|---|
| **Wright 路径系数法** | 血统书页展示 | 枚举五代内共同祖先,列出每条路径贡献 `(½)^(n1+n2+1)·(1+F_A)` |
| **Henderson 列表法** | 测试基准 | 标准加性亲缘关系矩阵 A,`a_ii = 1+F_i` |
| **记忆化共祖递归** | 生产热路径/配对预测 | `f(x,y)=[f(x,s_y)+f(x,d_y)]/2`,深度可剪枝 |

测试中三套算法在同一谱系上交叉验证,最大偏差为 0(见 `tests/inbreeding.test.ts`、`tests/pool-kinship.test.ts`)。

## 批量模拟的可扩展亲缘引擎

全群体 O(N²) 稠密矩阵在万级规模不可行。系统利用业务事实——**每代只有被选择指数截断的精英真正留种交配**——
实现 `DensePoolKinship`(`src/genetics/pool-kinship.ts`):

- 只维护育种池(默认 K≈2500)的加性亲缘矩阵,`Float64Array` 连续内存;
- 池内每个个体的双亲都在上一代池中,故池矩阵是全矩阵的**精确子矩阵,无近似**;
- 配对近交 O(1) 查表,世代推进 O(K²)。

## 性能实测(SLA)

`npm run bench` 实测(Windows / Node 24):

| 指标 | SLA | 实测 |
|---|---|---|
| 10,000 只 × 50 代全流程模拟 | ≤ 20 s | **≈ 13–15 s** |
| 五代血统书查询 | ≤ 100 ms | **均值 0.007 ms / 最慢 0.046 ms** |
| 近交三算法一致性 | 完全一致 | 最大偏差 0 |
| 累计出生 / 滚动留存 | 数据不丢 | 510,000 出生 / 90,000 留存,NDJSON 往返零丢失 |

模拟会输出天花板预警:默认选择压下 50 代后归巢触顶率(表型≥95)达 72%、速度 48%、耐力 24%。

## 数据持久化

- `PedigreeStore`:id 与鸽环号双 Map 索引,O(1) 查找;TypedArray 存微效位点控制内存。
- JSON 快照:带 magic `PIGEON-PEDIGREE-V1` 与版本/计数校验,拒绝非法文件。
- NDJSON 流式:首行清单头 + 逐行个体,面向几十万级大种群,内存占用恒定(`services/repository.ts`)。

## 关键设计取舍

- **可复现**:全部随机性经种子化 `Rng`(mulberry32 + Box–Muller),同 seed 结果逐只一致。
- **羽色预测用精确枚举而非蒙特卡洛**:六位点配子概率笛卡尔积,概率和严格为 1。
- **数量性状预测用解析正态近似**:孟德尔分离方差由亲本逐位点配子概率推出,叠加环境与近交。
- **模拟内存**:默认滚动留存最近 8 代完整个体,更早世代保留逐代统计摘要;需要全谱系时关闭 `retainGenerations`。
